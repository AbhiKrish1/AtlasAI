AtlasAI Coding Standards v1.0

1. Files should target 80–150 lines.
2. One class = one responsibility.
3. No print() in production code.
4. Use centralized logging.
5. Use custom exceptions.
6. Type hints are required.
7. Full-file replacements for code reviews.
8. Public methods should log major actions.
9. Private helpers encapsulate implementation details.
10. New architecture decisions require an ADR.
